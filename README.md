# ポストほりだし

Xのポストと交流を、ログインなしで掘り出すWebアプリです。スマホのブラウザで開くだけで使えます。

https://baris250209.github.io/horidashi/

## できること

| タブ | 中身 | 必要なもの |
|---|---|---|
| ベスト | IDを入れて「いいね◯以上」の段を押すと、伸びたポストの検索がXで開きます | IDだけ |
| あの日 | 1〜10年前の今日のポスト、ふたりの会話（相手のIDも入れる）、あなた宛てのリプ | ID |
| バズ | キーワードといいね数で、いま伸びているポストを探します | なし |
| 交流 | 交流番付、相性ベスト3、はじめて絡んだ日 | Xのアーカイブ |
| 通知表 | 書いた文字数・連続投稿・夜ふかし・口ぐせから、Xの通知表をつけます | Xのアーカイブ |
| 分析 | いいね・リポストなどの多い順、曜日と時間帯ごとの伸び具合（インプ・ブクマはCSVのとき） | Xのアーカイブ／アナリティクスのCSV |

番付・相性・通知表・ベスト3は画像にできます。保存した画像を添えて投稿してください。

## データについて

- 読み込んだファイルは、開いた端末の中だけで処理します。どこにも送信しません。
- 外から読み込むのは、見出しの文字（Google Fonts）だけです。
- 検索は、Xのアプリかサイトを開くだけです。見られる範囲はXの表示と同じです。
- ボタンを押したときだけ、Xの検索・投稿画面や、端末の共有を開きます。

## 注意

- 非公式のツールです。X Corp. とは関係ありません。
- `min_faves` などの検索コマンドはXの公式ヘルプに載っていないもので、仕様が変わると動かなくなることがあります。
- 相性度と通知表の評価は、ポストの数字から計算した遊びの指標です。

## 中身

`index.html` 1枚で動きます。`tests/` に、架空のデータを使った読み込みと計算のテストがあります。
